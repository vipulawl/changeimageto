Instagram’s Image Size Guidelines

Instagram's evolving platform still maintains essential image size guidelines. Here’s a quick reference:

  • Square Photos: 1080 x 1080 pixels, 1:1 aspect ratio.
  • Portrait Photos: 1080 x 1350 pixels, 4:5 aspect ratio.
  • Landscape Photos: 1080 x 566 pixels, 1.91:1 aspect ratio.
