Tips for best results

  • Use a well-contrasted source image. The AI performs best when the subject is clearly distinct from the original background. A person in front of a plain wall is easier to process than a person wearing clothes that match the background color.
  • Upload in PNG for complex edges. PNG files preserve more edge detail around hair, fur, and fine textures than compressed JPGs.
  • Check the edges before downloading. Zoom in to the preview around hair and object boundaries. If any artifacts appear, the tool typically lets you refine or re-upload.
  • Use JPG output for solid-color backgrounds. If you're adding a solid color (not transparency), JPG results in a smaller file size without quality loss.
  • Batch similar images together. If you're processing a product line, do all images at once so the background color is consistent across the entire set.
